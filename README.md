# 效期管家 Inventory App

獨立的進貨、效期、庫存、領用管理靜態專案。第一版先用瀏覽器 `localStorage` 保存資料，方便快速試用；未來可把資料層替換成 Supabase / PostgreSQL 或 Firebase。

## 第一版功能

- 進貨登錄：品項、類別、單位、數量、安全庫存、效期、批號、位置
- 庫存查詢：品項總量、最早到期日、位置、狀態
- 領用扣庫存：依 FEFO 先到期先出庫
- 提醒摘要：30 天內到期、已過期、低庫存
- 批號庫存：保留每批效期與位置
- 異動紀錄：記錄進貨與領用
- JSON 匯出：可備份目前瀏覽器資料

## 使用方式

直接開啟 `inventory-app/index.html` 即可使用，不需要建置流程。

## 後續接後端建議

核心資料表可對應為：

- `items`: 品項、類別、單位、安全庫存、條碼
- `stock_batches`: 品項、批號、效期、數量、位置
- `stock_movements`: 進貨 / 領用 / 調整 / 報廢紀錄
- `users`: 使用者與權限
